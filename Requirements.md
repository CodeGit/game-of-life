Conways game of life
1. Player choices should be remembered across sessions
2. Player should be able to share choices
3. Players should be able to edit the grid and run/pause
4. The game should have parameters to permit changing/importing rules
5. The game should be have common patterns and presets
6. The game should run as a pwa on a server accessible to the internet
7. The majority of the processing should occur on the client to keep server usage manageable
8. The game should run in a container for easy tear down

Future
1. The game should be cloud-deployable via simplified k8s or cloud runners
2. A multiplayer mode where 2 or more players combine their biomes
